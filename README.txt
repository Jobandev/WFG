Wolfgramm Holdings website

Open index.html for the parent homepage. The outcomes pages use clean folder routes:
- relational/index.html
- digital/index.html

All pages share style.css and app.js. The theme tokens, typography, spacing and interaction states are defined in style.css.
WH Short Message Service and free-resource buttons open WhatsApp with a pre-filled message. Outcomes pages also link to the live workshops calendar and contact page.
Fonts load from Google Fonts with local fallbacks. Animations respect reduced-motion preferences.

WH Short Message Service (WH SMS) is the approved service name. The current website opens WhatsApp with pre-filled messages; it does not implement SMS delivery, automated follow-up or a CRM backend. Campaign #2 copy must follow the signed Cyber Resilience Proposal once that document is supplied.
